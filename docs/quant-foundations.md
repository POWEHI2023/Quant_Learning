# 量化研究基础

## 从想法到可检验策略

量化策略至少包含五层：投资假设、可观测信号、组合构建、成交模型、绩效评估。把五层混在一个脚本里，很容易把数据问题误认为投资能力。因此本项目把数据适配、选股、成交和评估分别实现。

本策略的假设是“科技行业内较小的公司可能获得规模风险溢价”。Banz 的经典研究发现小公司平均风险调整收益较高，但也明确指出规模可能只是其他未知风险的代理变量；Fama 与 French 后续研究将规模与账面市值比纳入横截面解释。这些是研究动机，不是收益保证：

- [Banz (1981), The Relationship Between Return and Market Value of Common Stocks](https://doi.org/10.1016/0304-405X(81)90018-0)
- [Fama & French (1992), The Cross-Section of Expected Stock Returns](https://doi.org/10.1111/j.1540-6261.1992.tb04398.x)

## 回测最容易犯的错误

- 未来函数：用调仓日收盘价或后来发布的财务数据生成当日订单。
- 幸存者偏差：用今天仍上市的股票列表回测过去。
- 成分股偏差：用今天的行业或指数成分代替历史成分。
- 价格处理错误：忽略分红送转，或混用复权价格和真实涨跌停价。
- 成交过度乐观：假定停牌、涨跌停和低流动性股票都能按收盘价成交。
- 成本遗漏：小市值组合的冲击成本和最低佣金占比往往更高。
- 过拟合：根据同一段历史不断调整阈值，再把样本内最优结果当成预测能力。

第一版通过历史日期截面、信号/执行日分离、流动性过滤和显式成本模型处理其中大部分问题。盘口冲击、历史分段税费和财务质量因子留作后续版本。

## 如何读绩效

- 总收益和年化收益描述增长速度，但不表达路径风险。
- 年化波动率描述日收益波动，不等于最大可能损失。
- 夏普比率是单位波动对应的超额年化收益，对非正态、短样本很敏感。
- 最大回撤描述历史峰值到后续谷值的最大跌幅。
- 相对基准收益用于判断策略是否只是承担了市场方向风险。

正式研究还应加入滚动回测、样本外区间、参数敏感性、换手率、容量估计、行业暴露和因子归因。不要只保留一次“最好看”的回测。
